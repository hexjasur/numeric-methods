🚀 How to Add Dark Mode to Your Pages

Step 1: Add to Your HTML Head (2 lines)

Add these lines to the <head> section of your HTML file:

<head>
  <!-- Your other meta tags and styles -->
  
  <!-- DARK MODE -->
  <link rel="stylesheet" href="path/to/dark-mode.css">
  <script src="path/to/dark-mode.js"</script>
</head>

Step 2: Use CSS Variables (Optional)

Your CSS automatically uses the theme variables. But if you want custom styling:

/* Light mode (default) */
.my-element {
  background-color: var(--bg-primary);
  color: var(--text-primary);
  border-color: var(--border-color);
}

/* Automatically switches in dark mode! */

Step 3: Done!

That's it! The dark mode toggle button appears automatically in the top-right corner. All your elements automatically theme themselves.

🎨 CSS Variables Available

All CSS variables update automatically when dark mode is toggled.

Background Colors

  • --bg-primary — Main background color
  • --bg-secondary — Secondary background (hover states)
  • --bg-tertiary — Tertiary background
  • --card-bg — Card/container background
  • --input-bg — Input field background
  • --button-bg — Button background

Text Colors

  • --text-primary — Main text color
  • --text-secondary — Secondary text (lighter)
  • --text-tertiary — Tertiary text (even lighter)
  • --button-text — Button text color
  • --input-text — Input text color

Accent & Border Colors

  • --accent-primary — Primary accent (#00f2ff cyan)
  • --accent-secondary — Secondary accent (#ff00ea magenta)
  • --border-color — General border color
  • --border-dark — Dark border color
  • --card-border — Card border color
  • --input-border — Input border color
  • --button-border — Button border color

💻 JavaScript API (Advanced)

If you need to control dark mode programmatically:

// Get current theme
const theme = window.DarkMode.get(); // 'light' or 'dark'

// Set to dark mode
window.DarkMode.set('dark', true);

// Set to light mode
window.DarkMode.set('light', true);

// Toggle between themes
window.DarkMode.toggle();

// Listen for theme changes
window.addEventListener('theme-changed', (e) => {
  console.log('Theme changed to:', e.detail.theme);
});

📞 Troubleshooting

Toggle button not appearing?

  • Check that dark-mode.js is loaded (Open DevTools → Network tab)
  • Check browser console (F12) for JavaScript errors
  • Ensure the file path is correct relative to your HTML file

Colors not changing?

  • Check that dark-mode.css is loaded (DevTools → Network)
  • Verify data-theme="dark" is set on <html> element
  • Make sure no other CSS is overriding the colors

Flickering on page load?

  • Ensure dark-mode JS is in the <head>, not at the end of <body>
  • It should be one of the first scripts to run
