💻 JAVASCRIPT API (Advanced)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Get current theme:
  window.DarkMode.get()  // Returns: 'light' or 'dark'

Set theme:
  window.DarkMode.set('dark', true)   // true = animate transition
  window.DarkMode.set('light', true)

Toggle theme:
  window.DarkMode.toggle()

Inject toggle button manually:
  window.DarkMode.injectToggle()

Listen for theme changes:
  window.addEventListener('theme-changed', (e) => {
    console.log('Theme:', e.detail.theme);  // 'light' or 'dark'
  });

Problem: Toggle button not showing
Solution: 
  • Check DevTools (F12) → Network tab → dark-mode.js loaded?
  • Check Console for JavaScript errors
  • Verify file paths are correct

Problem: Colors not changing when toggling
Solution:
  • Check DevTools → Elements → <html> tag has data-theme="dark"?
  • Check dark-mode.css is loaded in Network tab
  • Check for CSS that overrides the variables

Problem: Page flickers when loading
Solution:
  • Ensure dark-mode.js is in <head>, not at end of <body>
  • It must run early before other content loads

Problem: Theme not saved after refresh
Solution:
  • Check if browser allows localStorage (not private window)
  • Check DevTools Console for storage errors
  • Safari private mode: localStorage disabled (expected)

✨ PRO TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Always add dark mode CSS/JS in the <head>, not at end of <body>
2. Use var(--text-primary) instead of hardcoding colors
3. The toggle button is auto-injected, you don't need to add it
4. localStorage key is 'theme-preference' (don't use it for other things)
5. Tab to the toggle button and press Space to toggle (keyboard accessible)
6. Dark mode CSS file is ~10KB, JS is ~4KB (minimal overhead)
7. To customize colors, edit the :root variables in dark-mode.css
8. The system respects user's OS dark mode preference automatically
9. Dark mode persists across all pages (global preference)
10. No frameworks needed - pure CSS and vanilla JavaScript
