## 📚 Foydalanish Qo'llanmasi

### Iteratsiya Usuli

1. **Kirish ma'lumotlarini kiriting:**
   - Boshlang'ich yaqinlashish (x₀)
   - Aniqlik (ε)
   - Iteratsiya soni

2. **Hisoblashni boshlang:**
   - "Hisoblash" tugmasini bosing
   - Natijalarni kuzating

3. **Natijalarni tahlil qiling:**
   - Har bir iteratsiya bosqichini ko'ring
   - Xatolik darajasini tekshiring

### Kesmani Teng Ikkiqa Bo'lish Usuli

1. **Oraliqni belgilang:**
   - a va b qiymatlarini kiriting
   - Aniqlik darajasini tanlang

2. **Hisoblash jarayoni:**
   - Avtomatik hisoblash
   - Bosqichma-bosqich natijalar

3. **Yakuniy natija:**
   - Ildiz qiymati
   - Iteratsiya soni
   - Xatolik darajasi

### Funksiya Kesishish Nuqtasi

1. **Funksiyalarni kiriting:**
   - f(x) va g(x) funksiyalarni yozing

2. **Grafikni chizing:**

## 📝 Muhim Eslatmalar

### Foydalanishda E'tibor Beriladigan Jihlar

1. **Matematik ifodalarni to'g'ri yozish:**
   - `x^2` o'rniga `Math.pow(x, 2)` yoki `x*x`
   - `sin(x)` o'rniga `Math.sin(x)`
   - `e^x` o'rniga `Math.exp(x)`

2. **Aniqlik darajasi:**
   - Kichik qiymatlar (0.001, 0.0001) aniqroq natija beradi
   - Lekin hisoblash vaqti uzayadi

3. **Boshlang'ich qiymatlar:**
   - To'g'ri tanlangan boshlang'ich qiymat tezroq yaqinlashishni ta'minlaydi
   - Oraliqda ildiz mavjudligini tekshiring

### Xatoliklar bilan Ishlash

- **Chegaralangan qiymatlar** - Funksiya qiymatlari chegaralanganligini tekshiring
- **Iteratsiya chegarasi** - Juda katta iteratsiya soni ishlashni sekinlashtirishi mumkin
