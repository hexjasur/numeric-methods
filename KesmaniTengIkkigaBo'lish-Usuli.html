📚 USUL HAQIDA

Kesmani teng ikkiga bo'lish usuli (Bisection method) - bu oraliqni qisqartirish orqali ildizni topish usulidir.

Asosiy qadamlar:

  • Oraliq [a, b] tanlanadi, bunda f(a) · f(b) < 0
  • Oraliq markazi c = (a + b)/2 hisoblanadi
  • Agar f(c) = 0 bo'lsa, ildiz topildi
  • Aks holda f(a) · f(c) < 0 bo'lsa, yangi oraliq [a, c] bo'ladi
  • Shart |b - a| < ε bajarilguncha takrorlanadi

Afzalliklari: Har doim yaqinlashadi, oddiy va ishonchli

Kamchiliklari: Sekin yaqinlashadi, faqat bitta ildizni topadi
